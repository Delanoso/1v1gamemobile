# 1v1 Game Mobile

Mobile-friendly 1v1 game prototype starting with a Call of Duty Ghosts weapons armory viewer.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL on your phone (same Wi‑Fi) or in a browser.

## Play on iPad (Safari)

After deploy, open:

**https://delanoso.github.io/1v1gamemobile/**

## Assets

- `public/models/call_of_duty_ghost_-_weapons.glb` — COD Ghosts weapons collection
